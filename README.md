# Loan-Eligibility-Prediction-Project-using-Machine-Learning
Banks process numerous loan applications, making manual evaluation time-consuming. This project uses machine learning to predict loan eligibility based on factors such as income, credit history, employment, loan amount, education, and property area. The model aims to support faster, consistent, and data-driven loan screening decisions.
Libraries Used

The Loan Eligibility Prediction project uses Python libraries for data manipulation, numerical analysis, visualization, and machine learning.

1. Pandas

Pandas is used for data manipulation and analysis. It helps in loading the dataset, handling missing values, filtering data, creating DataFrames, and preparing the data for machine learning.

2. NumPy

NumPy is used for numerical operations and efficient handling of arrays and mathematical calculations. It supports data preprocessing and other numerical computations required during the analysis.

3. Matplotlib

Matplotlib is used for data visualization. It helps create graphs and charts to understand patterns and relationships in the loan application data, such as income, loan amount, credit history, and loan eligibility.

4. Scikit-learn

Scikit-learn is the main machine learning library used in this project. It is used for data preprocessing, splitting the dataset into training and testing sets, building machine learning models, and evaluating their performance.

The project uses Decision Tree and Naive Bayes classification algorithms to predict whether an applicant is likely to be eligible for a loan.

Project Workflow

Data → Pandas/NumPy → Data Visualization → Matplotlib → Preprocessing → Scikit-learn → Decision Tree & Naive Bayes → Model Evaluation → Loan Eligibility Prediction
